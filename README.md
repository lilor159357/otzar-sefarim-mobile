# אוצר ספרים — אפליקציית Android (Mobile)

אפליקציית מובייל (React + TypeScript + Capacitor) לניהול, איתור והשאלת ספרים בספריית הישיבה, מסונכרנת בזמן אמת מול תוכנת המחשב של **אוצר ספרים** דרך Firebase Cloud.

## יכולות עיקריות
- **חיפוש תורני ומפה דו-ממדית**: חיפוש חכם עם נרמול כתיב מלא/חסר, ראשי תיבות (שו"ע, רמב"ם, משנ"ב, ש"ס ועוד) וסריקת ברקוד ממצלמת הטלפון, כולל הדגשת הארון במפה הדו-ממדית.
- **השאלה והחזרה מהירה**: סריקת ברקוד להשאלה והחזרה בלחיצה אחת, רשימת ספרים באיחור עם חיוג מהיר לשואל.
- **צילום AI ישיר למחשב**: צילום מדף או כריכת ספר (דחיסה אוטומטית) ושידור לתור הקטלוג בתוכנת המחשב.
- **חיבור מהיר בלחיצה אחת**: ייבוא קוד `OTZAR-SETUP:...` או קובץ `.otzar-setup` מתוכנת המחשב כולל הגדרות Firebase וערכת הנושא.

## בניית APK אוטומטית (GitHub Actions)
בכל Push לענף `main` או דחיפת תגית גרסה (`v*.*.*`), GitHub Actions בונה אוטומטית את קובץ ה-APK (`Otzar-Sefarim-Mobile-<version>.apk`) ומפרסמת אותו תחת **Releases** / **Actions Artifacts**.
